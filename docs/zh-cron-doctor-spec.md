# Cron Doctor 规格说明

## 问题

当脚本被移动、工作目录消失、provider 运行失败或交付开始失败时，定时任务的健康状况可能会在无明显提示的情况下持续恶化。`hermes cron list` 会内联显示其中一部分信息，但当前没有一种紧凑的只读健康检查，可供终端、cron job 或 CI 风格的冒烟测试运行。

## 目标

新增 `hermes cron doctor` 只读诊断命令，用于汇总 cron job 健康状况，并在发现可操作问题时以非零状态码退出。

## 非目标

- 不修改任务，不自动修复状态。
- 不启动或停止 gateway。
- 不检查 secret，不打印凭据。

## 验收标准

- 当活动任务没有检测到问题时，`hermes cron doctor` 返回 `0` 并打印健康状态消息。
- 当任一活动任务存在以下问题时，命令返回 `1` 并按任务分组打印问题：
  - 上次运行失败（`last_status` 不是 `ok`）；
  - 上次交付失败；
  - 任务仍处于活动状态，却没有 `next_run_at`；
  - 启用了 `no_agent` 却未配置脚本；
  - 脚本路径不存在，或位于 `HERMES_HOME/scripts` 之外；或
  - 已配置的工作目录路径不存在。
- parser、命令分派和聚焦测试需覆盖这个新子命令。
